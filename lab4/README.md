
Программа представляет собой простую экспертную систему на языке CLIPS. Она помогает определить возможную неисправность компьютера на основе ответов пользователя.
Пользователь отвечает на вопросы о симптомах: включается ли компьютер, есть ли черный экран, шум, перегрев, зависания, синий экран, проблемы с интернетом и перезагрузки.
На основе введенных ответов система применяет набор правил и выводит возможный диагноз, а также совет по устранению проблемы.
