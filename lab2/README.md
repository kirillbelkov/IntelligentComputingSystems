По индивидуальному заданию 3 необходимо удалить все вхождения заданного элемента из списка. 
В программе используется рекурсия: список постепенно разбивается на голову и хвост, после чего голова сравнивается с элементом, который нужно удалить. 
Если голова списка совпадает с этим элементом, она не добавляется в итоговый список. 
Если голова не совпадает, она сохраняется, а программа продолжает обработку оставшейся части списка.
Например, если из списка `[a, b, a, c, a, d]` удалить элемент `a`, то в результате получится список `[b, c, d]`. 
Также в программе можно дополнительно подсчитать, сколько раз удаляемый элемент встречался в исходном списке.
